# Day 43 – Longest Substring Without Repeating Characters

## Problem

Given a string `s`, find the length of the **longest substring** without repeating characters.

A substring is a contiguous sequence of characters within a string.

Return the length of the longest such substring.


## Example 1

Input:  
s = "abcabcbb"

Output:  
3

Explanation:  
The answer is "abc", with length 3.

## Example 2

Input:  
s = "bbbbb"

Output:  
1

Explanation:  
The answer is "b", with length 1.

## Example 3

Input:  
s = "pwwkew"

Output:  
3

Explanation:  
The answer is "wke", with length 3.  
Note that "pwke" is not a substring (it is a subsequence).
