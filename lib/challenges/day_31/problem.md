# Day 31 – Find the First Missing Positive Number

## Problem
Write a Dart function that takes a **list of integers** and returns the **smallest positive number (> 0) that is missing** from the list.

### Rules
- The list may contain:
    - negative numbers
    - zero
    - positive numbers
- The list is **not sorted**
- Use **loops and conditions**
- Do NOT use advanced built-in sorting or sets
- Focus on **logic**, not shortcuts

---

## Example 1
Input: [3, 4, -1, 1]  
Output: 2

Explanation:  
Positive numbers present → 1, 3, 4  
The smallest missing positive number is **2**

---

## Example 2
Input: [1, 2, 0]  
Output: 3

---

## Example 3
Input: [7, 8, 9, 11, 12]  
Output: 1
