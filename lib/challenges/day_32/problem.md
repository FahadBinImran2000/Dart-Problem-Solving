# Day 32 – Check if a List is Sorted (Ascending Order)

## Problem
Write a Dart function that takes a **list of integers** and returns `true` if the list is already **sorted in ascending order**, otherwise return `false`.

The list may contain:
- Positive numbers
- Negative numbers
- Duplicate values

The list will **not be empty**.

## Rules
- Do **not** sort the list
- Just **check the order**
- Use a loop and comparison logic

## Example

Input: [1, 2, 3, 4, 5]  
Output: true

Input: [1, 2, 2, 3]  
Output: true

Input: [3, 1, 4]  
Output: false

Input: [-5, -2, 0, 3]  
Output: true
