# Day 41 – Find the Longest Common Prefix

## Problem
Write a Dart function that takes a **list of strings** and returns the **longest common prefix** shared among all strings.

If there is **no common prefix**, return an **empty string** `""`.

## Rules
- Use **loops only**
- Do **not** use built-in prefix helpers
- Do **not** modify the original list
- The list will contain **at least one string**

## Example

Input: ["flower", "flow", "flight"]  
Output: "fl"

Input: ["dog", "racecar", "car"]  
Output: ""
