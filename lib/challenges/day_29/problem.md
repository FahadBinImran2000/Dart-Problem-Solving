# Day 29 – Check if a Number is Prime

## Problem
Write a Dart function that takes an **integer number** as input and returns **true** if the number is a **prime number**, otherwise return **false**.

A **prime number** is a number greater than 1 that has **only two divisors**:
- 1
- itself

### Rules
- Use **loops**, not built-in helpers
- Do **not** use advanced math libraries
- Assume the input number is **non-negative**

## Example

Input: 7  
Output: true

Input: 10  
Output: false

Input: 1  
Output: false

Input: 2  
Output: true
