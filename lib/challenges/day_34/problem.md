# Day 34 – Find the Majority Element in a List

## Problem
Write a Dart function that takes a **list of integers** and returns the **majority element**.

A **majority element** is a number that appears **more than n / 2 times**, where `n` is the size of the list.

You may assume that a majority element **always exists** in the list.

## Rules
- Do **not** use built-in helpers like `.where()`, `.reduce()`, or `.fold()`
- Use **loops and basic data structures**
- The input list will **not be empty**

## Example

Input:  
[3, 2, 3]  
Output:  
3

Input:  
[2, 2, 1, 1, 1, 2, 2]  
Output:  
2
